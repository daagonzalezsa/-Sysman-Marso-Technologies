Este repositorio presenta un esquema de como podría ser el proyecto para crear los modelos requeridos en la prueba.

<ul>
<li> En la carpeta <strong> model  </strong> la idea es que con el archivo <i> train.py <i> se harían todos los tests de los modelos que se piensan utilizar y comparar.
<li> En la carpeta <strong> model  </strong> la idea es que con el archivo <i> test.py <i> se harían los tests para comprobar que el modelo esté funcionando correctamente.
<li> En la carpeta <strong> model  </strong> la idea es que con el archivo <i> model.py <i> se guarden los modelos seleccionados después de las verificaciones
<i> En la carpeta de <strong> src </strong> se encuentra un archivo llamado <i> monitoreo.py </i> donde se guardarán las funciones de monitoreo necesarias para la implementación del monitoreo.
</ol>
